# Flexbox Layout Webpage

This project is a simple webpage layout created using HTML and CSS Flexbox. It demonstrates how different sections of a webpage can be organized using containers, rows, and columns. The layout includes a header, footer  areas arranged with Flexbox.

## Features

* Header and footer sections
* Sidebar navigation area
* Main content section
* Nested Flexbox containers
* Responsive layout structure using Flexbox
* Different background colors for visual understanding

## Technologies Used

* HTML
* CSS
* Flexbox


## Layout Overview

The webpage contains:

* Header section
* Left sidebar section
* Right content section

  * Top content area
  * Two bottom content boxes
* Footer section

This structure helps in understanding how Flexbox can be used to build modern webpage layouts.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
